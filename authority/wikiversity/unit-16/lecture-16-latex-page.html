\mathl{K\!-\!\operatorname{Spek}\, \left( R \right)}{} der Umgebungsfilter gehört und dass der Halm in diesem Filter gleich der Lokalisierung von $R$ an dem zugehörigen maximalen Ideal

{ }{ }

{ }{ }
