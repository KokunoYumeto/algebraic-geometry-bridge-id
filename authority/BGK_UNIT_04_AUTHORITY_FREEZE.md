## Frozen source anomalies

The authority bytes above remain unchanged. A later Indonesian reader should
apply only the following high-confidence repairs or clarifications, each with
an explicit correction record preserving the source form.

1. `AGC-BGK-U04-SRC-001`: the lecture root (page 109008, revision 1003714,
   SHA-1 `8eceb7ac307706e0858ffa278bd9d1235574a596`) has the heading
   `Garbenmorpismen`; the evident intended German word is
   `Garbenmorphismen` (sheaf morphisms).
2. `AGC-BGK-U04-SRC-002`: `Topologischer Raum/Garben/Morphismen/Garbe/Fakt/Beweis`
   (page 109520, revision 1112675, SHA-1
   `0b3734fdb9cb6552602b585fe837a473096d6b22`) checks and constructs only the
   component on sections over the top open set `U`. To prove that
   `V -> Mor(F|V,G|V)` is a sheaf, equality and gluing must be performed for
   every open `V subseteq U` using the cover `V intersection U_i`, and the
   resulting maps must be checked to commute with restrictions. The reader
   should state this standard completion rather than silently presenting the
   abbreviated proof as complete.
3. `AGC-BGK-U04-SRC-003`: `Hausdorffraum/Konstante Prägarbe/Keine Garbe/Aufgabe`
   (page 111897, revision 1098181, SHA-1
   `1ef282d42bf84eaf1653c6d128326805dda9e34d`) assumes only `M != emptyset`
   but concludes that the constant presheaf is not a sheaf. The conclusion is
   false for a singleton `M`; the intended hypothesis is that `M` has at least
   two elements.
4. `AGC-BGK-U04-SRC-004`: `Topologischer Raum/Garben/Morphismen/Gleichheitstest in Halmen/Fakt`
   (page 110249, revision 1049893, SHA-1
   `346f0e525acc77499a99fbe676bfcf8220c9b87c`) writes `alpha_p = beta_P`.
   The index must consistently be the previously quantified point `P`:
   `alpha_P = beta_P`.
5. `AGC-BGK-U04-SRC-005`: `Wolkenkratzergarbe/Gruppe/Garbeneigenschaft/Aufgabe`
   (page 139888, revision 1081969, SHA-1
   `8142855ff106a5da9990c7f6fc336c85309ca7dd`) says `Besitmme die Halm`.
   This is a double typographical error; the intended instruction is to
   determine the stalks (`Bestimme die Halme`) at all `Q != P`.
